# Sol

Sol is a macOS launcher: a panel you summon, type into, and pick from.

## The panel

**Sol**:
The launcher as a whole.
_Avoid_: the app, Spotlight

**Panel**:
The floating window Sol shows when summoned.
_Avoid_: window, popup, bar, overlay

**Widget**:
One mode of the panel. Search is the home mode. The others are File search, Clipboard, Scratchpad, Calendar, Translation, the emoji picker, Processes, and Settings.
_Avoid_: screen, page, view, tab

**Query**:
The text currently typed in the panel.
_Avoid_: search string, input, prompt

## Search

**Item**:
One choosable thing Sol can offer.
_Avoid_: result, entry, hit, app

**Catalog**:
The items Search ranks: applications, bookmarks, scripts, custom items, and built-in commands. Files are not part of the catalog.
_Avoid_: index, item list

**Search**:
The home widget. It ranks the catalog against the query.
_Avoid_: launcher, Spotlight

**Bookmark**:
A browser bookmark included in the catalog.
_Avoid_: favorite, link

**Script**:
A command the user has given Sol to run, included in the catalog.
_Avoid_: AppleScript, plugin

**Custom item**:
A link or command the user added to the catalog by hand.
_Avoid_: shortcut, alias

**Temporary result**:
An answer that exists only for the current query, such as a calculation or this machine's IP address.
_Avoid_: preview, snippet

**File search**:
The widget for finding files.
_Avoid_: Finder

**File index**:
The files File search can offer.
_Avoid_: database, cache, Spotlight index

**Search folder**:
A folder whose files belong in the file index. Settings lists these as File Search Paths.
_Avoid_: watch path, root, indexed directory

**Place name**:
A city, region, or country already attached to a photo, a video, an audio file, or a map link.
_Avoid_: location, coordinates, metadata, GPS

**Map link**:
A link file whose target is a map.
_Avoid_: Maps widget, calendar location

## Other modes

**Clipboard**:
Sol's list of recent copies.
_Avoid_: pasteboard, clipboard manager, history

**Scratchpad**:
The note kept in the panel.
_Avoid_: notes, notepad

**Calendar**:
The widget that shows events.
_Avoid_: schedule, agenda, menu bar

**Upcoming event**:
The next event Sol shows in the menu bar.
_Avoid_: calendar

**Translation**:
The widget that translates the query between the chosen languages.
_Avoid_: translator

**Emoji picker**:
The widget for choosing an emoji or a symbol.
_Avoid_: symbols

**Processes**:
The widget that lists running processes so one can be quit.
_Avoid_: process killer, Activity Monitor

## Keys

**Global shortcut**:
The key combination that summons the panel.
_Avoid_: hotkey, item shortcut

**Item shortcut**:
A key combination bound to one item. The settings heading for these is Global Shortcuts.
_Avoid_: global shortcut, hotkey

**Hyper key**:
Caps Lock acting as command, option, control, and shift together.
_Avoid_: caps lock, hyper

**Query history**:
Queries already submitted, kept so they can be stepped back through.
_Avoid_: history, clipboard
